# Ad Film — 高端广告感 AI 短片提示词生成器

根据产品信息，生成一套完整的「高端广告感」AI 短片提示词：分镜海报生图提示词 + 视频生成提示词。

核心理念：**信息密度低，情绪密度高。** 不展示产品参数，而是用氛围打动人。

作者：非著名程序员

## 触发方式

用户提供产品信息，格式示例：

- "帮我做一个智能手表的广告短片"
- "产品是一款高端咖啡豆，品牌名：深山咖啡"
- "帮我做一瓶精酿啤酒的广告，品牌叫麦浪"

## 执行流程

### Step 1：获取产品信息

从用户输入中提取以下信息（缺失项主动询问或合理补全）：

| 字段 | 说明 | 示例 |
|------|------|------|
| 产品类型 | 产品所属品类 | 篮球鞋、香水、咖啡、耳机、腕表... |
| 品牌名 | 中文品牌名 | 破界、雾栖 |
| 英文名 | 英文品牌名 | BREAKPOINT、VIRELIS |
| 产品名称 | 具体产品名 | 高性能篮球鞋、淡香精 |
| 品牌标语 | 一句品牌主张 | 落地之前先突破自己 |

如果用户没有提供品牌名/标语，根据产品调性**自行创作**，但要告知用户这些是生成的，可以修改。

### Step 2：分析产品调性，确定节奏方向

根据产品类型判断广告节奏，这是最关键的决策：

| 节奏类型 | 关键词方向 | 适合产品 | 镜头节奏 |
|---------|-----------|---------|---------|
| **力量爆发型** | 爆发、压迫、速度、对抗、冲击、滞空 | 运动鞋、能量饮料、汽车、电竞设备 | 快→慢→爆→静 |
| **呼吸留白型** | 慢、柔、雾、留白、漂浮、安静 | 香水、护肤品、茶叶、睡眠产品 | 极慢、连续流动 |
| **质感沉浸型** | 精密、光泽、温度、层次、匠心 | 咖啡、腕表、威士忌、巧克力 | 中速、微距+全景交替 |
| **科技冷峻型** | 锐利、冷光、极简、未来、精密 | 耳机、手机、智能家居、笔记本 | 冷静克制、几何构图 |
| **生活温度型** | 阳光、自然、日常、温暖、真实 | 咖啡豆、面包、家居用品、宠物用品 | 自然流动、生活场景 |

大部分产品可以归入以上某一类，也可以是两类的混合。判断时以产品的**情绪联想**为依据，不是以功能为依据。

### Step 3：设定视觉系统

#### 3.1 主色调

根据产品调性选择：

| 调性 | 主色调 | 示例 |
|------|-------|------|
| 力量爆发 | 深灰黑、冷银、霓虹蓝 | 篮球鞋 |
| 呼吸留白 | 冷柔乳白、浅灰紫雾 | 香水 |
| 质感沉浸 | 暖棕、深琥珀、奶油白 | 咖啡 |
| 科技冷峻 | 纯黑、冷灰银、蓝白光 | 耳机 |
| 生活温度 | 暖黄、自然绿、木色 | 家居 |

#### 3.2 主角设定

根据产品目标人群设定主角（性别、气质、穿着），要具体到可执行的描述。
- 人物气质必须与品牌调性一致
- 穿着极简，不抢产品的视觉注意力
- 明确种族/外貌特征，确保生图一致性

#### 3.3 产品外观

描述产品的视觉特征：
- 材质（玻璃、金属、皮革、织物...）
- 配色
- 关键设计元素
- 品牌标识位置

### Step 4：设计 12 个分镜

这是核心创作环节。12 个镜头必须构成一个**完整的情绪弧线**。

#### 通用镜头结构

```
1-2：环境建立（营造氛围空间）
3-4：人物入场 + 产品初次出现
5-6：使用准备/蓄力（动作渐起）
7-8：核心动作/高潮前奏
9-10：高潮/爆发/最美瞬间
11：收束/余韵
12：主镜（Hero Shot — 产品独立画面 + 品牌 LOGO + 标语）
```

#### 镜头设计原则

- **动作描述只占 20%，氛围描述占 80%**
- 每个镜头必须明确：人物在做什么、光线从哪来、画面情绪是什么
- 镜头之间要有**情绪递进**，不能平铺直叙
- 最后一个主镜（Hero Shot）必须是产品独立画面，品牌 LOGO 和标语出现
- 不要写"展示产品"这种功能性描述，要写"光线落在产品表面"这种氛围性描述

### Step 5：选择关键词

从以下关键词库中选取适合的词，写入提示词。**不要全用，选 5-8 个最契合的。**

#### 光影类
```
柔白晨光、聚光灯、体积光、玻璃高光、自然逆光、冷调边缘光、雾面反射、电影级光影
```

#### 空气感类
```
空气粉尘、香雾粒子、薄雾、呼吸感、空间留白、漂浮感、空气流动
```

#### 镜头语言类
```
慢推近、低机位跟拍、浅景深、柔焦背景、慢动作、轻微横移、高速残影、镜头呼吸感
```

#### 材质类
```
丝绸、玻璃、金属反光、皮革纹理、水珠、磨砂材质、木地板反光、高级纸面纹理
```

### Step 6：生成提示词

输出两段提示词，用 markdown code block 包裹。

#### 6.1 分镜海报生图提示词

格式：

```
请创作一张高端【产品类型】广告「【氛围主题名】」分镜海报，竖版 9:16，3列 × 4行，共12个镜头。

品牌名：【品牌名】
英文名：【英文名】
产品：【产品名称】
标语：【品牌标语】

整体为【主色调】背景，带轻微高级纸张纹理。
顶部居中标题【品牌名】，下方为【英文名 · 产品名称】和品牌标语。
中间是12格分镜，每格上半部分为电影感画面，下半部分为中文分镜说明。

视觉风格：
【整体视觉关键词，5-8个，从关键词库中选取】

主角：
【人物描述：性别、外貌、穿着、气质】

产品：
【产品外观描述：材质、配色、设计细节、品牌标识】

12个镜头顺序：
【镜头1】→【镜头2】→...→【主镜头】

每个镜头需具有明确电影感：
1. 【镜头名】：【画面描述，包含动作+氛围+光线】
2. ...
12. 主镜：【Hero Shot 描述】

整体画面强调：
高级商业广告感、电影级光影、真实摄影质感、极简排版、统一配色、情绪递进。

最终效果像真正国际品牌发布会上的 storyboard 分镜海报。
```

#### 6.2 视频生成提示词

格式：

```
请根据这张高端【产品类型】广告分镜图，生成一支完整的「【氛围主题名】」广告短片，时长约15秒，竖版 9:16。

请保持分镜图中的镜头顺序、产品外观、人物气质和整体【主色调】调性。整体为【氛围关键词】。

视频依次表现：
【12个镜头的简短动作描述，用 → 连接】

主角为【人物描述简版】。产品为【产品描述简版】。

镜头语言：【运镜关键词，4-6个】

画面强调：
高级商业广告感、电影级光影、克制配色、真实摄影质感、【产品特有氛围词】。

不要字幕，不要分镜框，不要海报排版，【根据产品补充 3-4 个"不要"】。
```

### Step 7：输出格式

最终输出结构：

```markdown
## 【品牌名 · 产品名】广告短片提示词

### 产品分析
- **产品类型**：xxx
- **节奏方向**：xxx型
- **情绪关键词**：xxx
- **品牌名**：xxx / 英文名
- **标语**：xxx

---

### 一、分镜海报生图提示词

【完整提示词，code block 包裹】

---

### 二、视频生成提示词

【完整提示词，code block 包裹】
```

## 核心原则（必须遵守）

1. **氛围 > 产品**：提示词中 80% 的篇幅在描述光线、空气、材质、情绪，只有 20% 在描述产品本身
2. **具体 > 抽象**：不要写"高级感""电影感"，要写"冷黑银调、聚光灯边缘光、空气粉尘"
3. **否定指令必须写**：结尾的"不要"列表和正面描述同等重要
4. **12 镜头有弧线**：不是 12 个独立画面，而是一个完整的情绪递进故事
5. **Hero Shot 收尾**：最后一个镜头必须是产品独立画面 + 品牌 LOGO + 标语
6. **节奏匹配产品**：运动产品用快节奏，香氛产品用慢节奏，不能乱用
7. **人物极简**：主角穿着和气质服务于产品，不能抢注意力

## 禁止事项

- 禁止写"一个人拿着 XX 产品"这种直白的产品展示
- 禁止用"高级感""电影感""大片感"等抽象词作为主要描述
- 禁止 12 个镜头平铺直叙没有情绪起伏
- 禁止出现功能参数描述（容量、尺寸、配置等）
- 禁止短视频/vlog/电商展示风格的镜头语言
- 禁止卡通风格、综艺运镜、廉价滤镜

# Poster Prompt Reference

Use this reference to create ecommerce advertising poster prompts.

## Prompt Template

```text
Ecommerce advertising poster for [product], targeting [customer], focused on [main benefit].
Composition: [layout], product as the clear hero, [foreground/background details].
Style: [brand tone], [lighting], [color palette], high-end commercial photography, clean visual hierarchy.
Marketing space: leave readable empty space for [headline/offer/logo].
Platform: optimized for [ratio/platform].
Avoid: clutter, fake UI, distorted product, unreadable text, exaggerated claims.
```

## Required Prompt Parts

- Product identity: exact product type, material, color, size, package, or variant.
- Buyer context: who wants it and why.
- Selling angle: one clear reason to buy.
- Visual scene: studio, lifestyle, seasonal, bundle, comparison, or marketplace.
- Composition: product scale, camera angle, depth, negative space.
- Brand tone: premium, playful, practical, minimalist, bold, fresh, cozy, technical.
- Platform fit: square, vertical, banner, marketplace thumbnail, story, feed post.

## Creative Angles

- Premium: clean studio, controlled lighting, elegant surfaces, sparse copy space.
- Practical: show usage context, problem-solution framing, clear benefit hierarchy.
- Social-commerce: brighter color, stronger offer area, energetic composition.
- Seasonal: holiday, summer, back-to-school, gifting, new year, limited campaign.
- Bundle: grouped products, value stack, offer space, simple comparison cues.
- Lifestyle: product in a natural moment, human context without distracting from the product.
- Comparison: before/after or old/new only when claims are supplied and allowed.

## Variant Set

When the user asks for options, default to three variants unless the user asks for a different count:

1. Premium conversion poster.
2. Social-commerce promotional poster.
3. Lifestyle product hero poster.

Each variant should include:

- Concept name.
- Best use case.
- Final English image prompt.
- Optional negative prompt.

## Negative Prompt

Use only when helpful:

```text
cluttered layout, unreadable text, misspelled words, distorted product, warped logo, fake brand marks, low resolution, messy background, exaggerated claims, medical claims, unrealistic before and after result
```

## Claim Safety

- Do not invent discounts, certifications, awards, clinical results, or performance numbers.
- Rephrase unsupported claims as visual mood or user benefit.
- Keep regulated categories conservative: health, beauty, finance, baby products, supplements, electronics safety.
